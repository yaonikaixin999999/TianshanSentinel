# 测试与验收方案

## 1. 测试层次

- 单元测试：后处理、叠加图、数据加载和模型输出尺寸。
- API 测试：健康检查、上传分析、详情查询。
- 构建测试：Vue 生产构建。
- 模型测试：训练后运行测试集评估和 ONNX 一致性。
- 人工验收：桌面与手机布局、图像滑块、历史恢复、错误状态。

## 2. 自动测试

```bash
pytest
cd frontend && npm run build
```

通过标准：测试进程返回 0，Vite 生成 `dist/`，控制台无编译错误。

## 4. 模型验收

执行 `evaluate.py` 产生 `metrics.json`。检查字段完整、样本数符合测试集、所有指标在 0-1 范围。随机抽取真阳性、假阳性、假阴性样例进行误差分析，至少覆盖：

- 小目标漏检。
- 大建筑边界破碎。
- 光照或季节变化误检。
- 配准误差造成的双边缘。
- 稳定区域正确抑制。

## 5. ONNX 一致性

从测试集取 20 对样本，比较 PyTorch 与 ONNX 的 logits 或概率。记录平均绝对误差和最大误差。若差异超过可解释的浮点误差，检查预处理、温度参数和 opset。

## 6. 演示验收清单

- 顶部引擎状态与实际后端一致。
- 示例载入、分析按钮、加载态、错误态正常。
- 图像滑块不改变布局尺寸。
- 风险标签有文字，不只依赖红黄绿。
- 刷新页面后历史仍在。
- 断开后端时页面显示服务未连接。
