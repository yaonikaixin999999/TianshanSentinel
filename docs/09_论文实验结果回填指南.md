# 论文实验结果回填指南

当前课程论文已完成背景、方法、需求、设计、实现、实验方案、局限和参考文献。由于本机未执行云 GPU 训练，论文中的结果表明确标记为“待训练后回填”，没有虚构数值。

## 1. 产生真实结果

按 `06_云GPU训练与部署指南.md` 完成训练、校准和评估，得到：

- `artifacts/levir_cd_run/summary.json`
- `artifacts/levir_cd_run/history.json`
- `artifacts/metrics.json`

## 2. 回填项目

| 论文位置 | 来源 |
|---|---|
| 训练硬件、耗时 | summary.json 与云实例信息 |
| 最佳 epoch | best.pt 或 history.json |
| Precision/Recall/IoU/F1 | metrics.json |
| 模型大小 | model.onnx 文件大小 |
| CPU 推理时延 | 本机预热后多次计时 |
| 成功/失败样例 | 测试集可视化，不挑选训练集 |

## 3. 计时方法

先预热 10 次，再连续推理 100 次，报告均值、P50 和 P95，同时写明 CPU 型号、线程数和图像尺寸。不能只报告最快一次。

## 4. 论文措辞

正确：在 LEVIR-CD 测试集上，模型取得 IoU 为 X、F1 为 Y。

错误：系统可准确检测新疆所有生态变化。公开建筑变化数据不能支撑该结论。

正确：实验表明该实现能够完成公开数据集上的建筑变化分割，并具备本地部署可行性。
