# 数据集与标注规范

## 1. 推荐公开数据

首选 LEVIR-CD。原始数据集面向建筑变化检测，包含 637 对 1024 x 1024、0.5 m 分辨率的双时相遥感图像及二值标签。使用前应阅读官方许可并在论文中引用：Hao Chen and Zhenwei Shi, *A Spatial-Temporal Attention-Based Method and a New Dataset for Remote Sensing Image Change Detection*, Remote Sensing, 2020.

本项目的可复现实验使用标准 256 x 256 裁剪版，共 7120 对训练样本、1024 对验证样本和 2048 对测试样本。`scripts/prepare_levir_cd.py` 固定到 Hugging Face 数据仓库 `ericyu/LEVIRCD_Cropped_256` 的提交 `70f91f6c`，下载后会记录 Parquet 的 SHA-256，并把标签统一二值化为 0/255 PNG。该镜像只用于下载便利，论文仍须引用 LEVIR-CD 原始论文。

项目不随源码再分发完整数据集，仅包含来自测试集样本 `001097` 的两张演示影像。原始影像和标签仅限学术用途，详细来源与使用条件见 `THIRD_PARTY_NOTICES.md`。可自动下载并准备本次实验数据：

```bash
python scripts/prepare_levir_cd.py
```

若采用官方下载或其他可信来源，则按以下结构整理：

```text
data/LEVIR-CD/
  train/A/*.png
  train/B/*.png
  train/label/*.png
  val/A/*.png
  val/B/*.png
  val/label/*.png
  test/A/*.png
  test/B/*.png
  test/label/*.png
```

同一对影像和标签必须同名。标签中 0 表示未变化，255 表示变化。数据准备脚本会在 `data/LEVIR-CD/dataset_manifest.json` 中保存来源、版本、样本数和文件校验值。

## 2. 校验

```bash
python scripts/validate_dataset.py --root data/LEVIR-CD
```

脚本要求 train、val、test 都存在且每个样本在 A、B、label 中都有同名文件。开始完整训练前，建议人工打开随机 20 对图像检查时相顺序和标签方向。

## 3. 新疆本地样本规范

若补充本地数据，建议采用公开、合规或已授权的影像。两期影像应满足：

- 同一坐标系、同一地面采样距离和相近季节。
- 覆盖同一地理区域且视场重叠充分，不得将两张无关照片作为双时相输入。
- 宽高比应一致；允许分辨率不同，但系统会将后时相缩放到前时相尺寸后再配准。
- 云、阴影和积雪不应直接标为地物变化。
- 配准误差原则上小于 1-2 个像素。
- 标签只描述可确认的实体变化，不把不确定边界强行二值化。

在线分析会在模型推理前执行输入质量门控。系统综合检查宽高比、ORB 共同特征、RANSAC 内点比例与空间覆盖，以及单应变换是否出现翻转、过度拉伸或越界。未通过时 API 返回 `422`“影像不可比较”，不会把无效输入错误记录为 0% 变化。

建议保存元数据：影像日期、来源、坐标系、GSD、区域名称、标注人、复核人、许可和脱敏状态。

## 4. 切分原则

不得把同一大图切出的相邻块随机分散到训练和测试集，否则会造成空间泄漏。应先按地理区域分组，再切分为 train、val、test。最终论文必须写明切分方法。

## 5. 数据增强

当前实现包含同步水平翻转、垂直翻转和 90 度旋转。增强必须同时作用于 A、B 和标签。不要对两个时相分别随机裁剪或分别做几何变换。

## 6. 数据伦理

- 不公开包含敏感设施或个人隐私的高分辨率影像。
- 不使用来源不明的网络图片冒充遥感数据集。
- 公开数据上的模型不能直接宣称适用于新疆所有地貌。
- 本地测试样本应记录许可和使用范围。
