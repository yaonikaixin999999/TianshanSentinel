# 天山哨兵平台功能使用指南

## 1. 功能导航

平台包含五个正式工作区：监测总览、智能研判、监测项目、斑块复核和成果中心。桌面端使用左侧导航，移动端使用顶栏下方的粘性导航。

## 2. 监测项目

项目用于组织同一区域的连续分析记录。项目字段包括名称、区域、可选中心坐标、说明、状态和变化率预警阈值。

系统升级前产生的记录自动归入“历史检测任务”，不会删除旧结果。项目详情页显示分析数、变化斑块、待复核数、多时相趋势和阈值状态。

## 3. 双时相与多时相分析

双时相模式接收一组前后影像，并保存前后时相标签。多时相模式接收至少两期影像，按文件名排序，对相邻影像依次生成分析任务。例如 2023、2024、2025 三期影像会生成 2023-2024 和 2024-2025 两条记录。

每组影像仍必须覆盖同一地区，并具有接近的比例尺、方向和范围。质量门判定不可比较时，当前组返回 `422`，不会保存虚假变化率。

## 4. 事件类型建议与人工复核

模型负责输出二值变化区域。系统根据变化区域前后的边缘密度和亮度差异提供以下规则型建议：疑似新增建设、疑似拆除清理、疑似地表改造和其他变化。

该建议不是多分类模型结论。复核人员应在影像对比界面中确认或排除斑块，并可修改事件类型、填写备注。每个结果保存待复核、已确认或已排除状态，项目与总览统计会同步更新。

## 5. 变化预警

每个项目配置独立变化率阈值，范围为 1%-50%。项目最近一次分析的变化率达到阈值时，总览生成项目预警。预警只用于排序和提示，不代替人工判定。

## 6. 成果导出

单次分析可导出：

- DOCX 审计报告：项目元数据、核心指标、叠加影像、前后影像、斑块清单和方法限制。
- PDF 定版报告：适合归档、打印和答辩展示。
- GeoJSON：每个变化斑块的多边形、面积、风险、事件类型和复核状态。

项目可导出 CSV 时间轴，包含时相、变化率、置信度、斑块数、风险和复核状态。

## 7. 空间坐标限制

PNG/JPEG 和普通截图通常没有坐标系、仿射变换和地面分辨率。本版本会以影像像素边界生成 GeoJSON，并写入 `coordinate_system=image_pixel`。只有增加 GeoTIFF 元数据解析后，才能可靠输出真实经纬度、平方米面积和 GIS 图层。

## 8. 数据闭环

人工复核结果已经进入 SQLite 审计记录，可作为后续新疆本地数据整理的来源。真正训练新增/拆除多分类模型时，应从已确认记录中导出样本，并继续保留独立地区测试集，避免训练集与验收集重叠。
