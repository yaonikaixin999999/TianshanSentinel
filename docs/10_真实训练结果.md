# 真实训练与增量微调结果

## 1. 实验范围

- 初始训练完成时间：2026-07-21；增量微调完成时间：2026-07-23
- 数据：LEVIR-CD 256 x 256 裁剪版，训练 7120 对、验证 1024 对、测试 2048 对
- 模型：共享 ResNet18 编码器、多尺度差异门控、U-Net 解码器
- 随机种子：2026
- 输入与批大小：256 x 256，batch size 8
- 训练硬件：NVIDIA GeForce RTX 3080 Ti 12 GB
- 框架：PyTorch 2.5.1+cu124，CUDA 12.4

数据来源、固定版本和 Parquet 校验值分别见 `artifacts/dataset_manifest.json` 与 `artifacts/dataset_parquet_checksums.txt`。公开数据不随项目压缩包再分发。

## 2. 初始与增量训练摘要

### 2.1 初始训练

| 项目 | 真实结果 |

| 最佳轮次 | 64 |
| 最佳验证 IoU | 0.825294 |
| 最佳验证 F1 | 0.904286 |
| 训练耗时 | 3125.74 秒（52 分 5.74 秒） |
| 峰值 PyTorch 显存 | 1198.57 MB |

逐轮原始记录见 `artifacts/levir_cd_run/history.json`，曲线见 `artifacts/training_curves.png`。曲线未做平滑处理。

### 2.2 增量微调

增量阶段从初始训练第 64 轮最佳权重继续训练，学习率降为 5e-5，并加入前后时相交换、两时相独立光照/色彩、局部软阴影和轻微模糊。训练器先计算源模型验证 baseline，并在独立目录保存权重，未覆盖源 checkpoint。

| 项目 | 真实结果 |
|---|---:|
| 请求增量轮数 | 30 |
| 实际增量轮数 | 21（patience=8 早停） |
| 源 checkpoint epoch | 64 |
| 干净验证最佳 epoch | 77（增量第 13 轮） |
| 干净验证最佳 IoU | 0.826543 |
| 最终部署候选 epoch | 85（增量最后一轮） |
| 最终候选干净验证 IoU | 0.825186 |
| 增量训练耗时 | 868.50 秒（14 分 28.50 秒） |
| 峰值 PyTorch 显存 | 1256.92 MB |

最终候选不是按单一干净 IoU 选择，而是比较源模型、干净集最佳模型和最后一轮模型在同一固定种子压力集上的表现。最终候选相对源模型的干净 IoU 仅变化 -0.000113，但三类受扰动场景平均 IoU 提高 0.175040。

| 验证场景 | 源模型 IoU | 最终候选 IoU |
|---|---:|---:|
| 干净 | 0.825299 | 0.825186 |
| 独立光照/色彩 | 0.632775 | 0.811139 |
| 局部阴影 | 0.669445 | 0.817848 |
| 混合扰动 | 0.617608 | 0.815960 |
| 受扰动平均 | 0.639943 | 0.814982 |

证据见 `artifacts/levir_cd_finetune/summary.json`、`history.json` 和 `robustness_comparison.json`。这些扰动来自确定性评估流程，不等同于新疆本地真实测试集。

温度缩放后，在验证集 0.20-0.80 范围内以 0.01 步长选择阈值。最终温度为 1.730929，阈值为 0.470000。测试集只用于最终报告，没有参与训练、压力集筛选或阈值选择。

| 指标 | 结果 |
|---|---:|
| Precision | 0.908038 |
| Recall | 0.894388 |
| IoU | 0.820103 |
| F1 | 0.901161 |
| Accuracy | 0.990005 |

证据文件为 `artifacts/metrics.json` 和 `artifacts/levir_cd_finetune/test_metrics.json`。旧正式模型的测试 IoU 为 0.815886、F1 为 0.898609，原始证据已备份到 `artifacts/archive/pre_finetune_20260723/`；新模型的 IoU 和 F1 分别提高 0.004217 和 0.002552。

## 5. ONNX 与轻薄本性能

- ONNX 大小：60.35 MB
- ONNX SHA-256：`ae9b1b2ea3b208227c84290a891ffd1806d399ddc48a8486270a4c5b84707101`
- ONNX Checker：通过
- PyTorch/ONNX 最大绝对误差：0.00001144
- PyTorch/ONNX 平均绝对误差：0.00000141
- 本机 CPU 单次前向 50 次：平均 70.43 ms，P50 70.19 ms，P95 77.93 ms

CPU 结果使用 ONNX Runtime 1.20.1、256 x 256、batch size 1，预热 10 次，只统计单次模型前向，不包含配准、滑窗、后处理、文件写入和 HTTP。证据见 `artifacts/onnx_verification.json` 与 `onnx_cpu_benchmark.json`。

部署层对大幅影像使用 256 与 384 像素、25% 重叠的多尺度滑窗，并将“前时相到后时相”和“后时相到前时相”的概率取最大值。该策略不改变模型权重或上述测试集指标，用于避免整幅长方形影像被拉伸为 256 x 256，以及注意力门顺序偏好导致的拆除漏检。推理耗时会随影像尺寸和窗口数量增长。

对于模型已给出多个变化种子、但因合成重绘或跨域色调导致掩膜碎裂的域外大图，部署层使用局部标准化差异、结构相似性、边缘密度和 CLAHE 外观差异构成结构证据，只保留与模型种子邻接的连通区域。该分支属于部署后处理，不参与上表 LEVIR-CD 指标；其输出引擎名带 `+structural-fusion`，扩展像素以更高不确定性记录。标准 256 x 256 输入直接使用模型结果，不进行结构扩展。回归测试覆盖大面积移除、全局亮度变化不扩展、标准样本不过度扩展以及长方形预配准。

## 6. 定性案例

测试集中共有 935 个含变化像素的样本。按单图 IoU 分布选取 5%、25%、50%、75%、90% 和 98% 分位案例，均保存为前时相、后时相、真值、预测四联图。

| 案例 | 样本 | 单图 IoU |
|---|---|---:|
| 低分 | 001288 | 0.000 |
| 下四分位 | 000822 | 0.730 |
| 中位 | 000882 | 0.832 |
| 上四分位 | 000515 | 0.875 |
| 高分 | 001097 | 0.900 |
| 接近最佳 | 000752 | 0.931 |

完整案例与选择说明位于 `artifacts/examples/`。网页演示使用高分案例 `001097` 的前、后时相；经配准质量门和增量微调 ONNX 双向推理后的变化占比为 5.411%，共得到 5 个有效斑块。标准样本不会触发结构扩展。低分样本说明模型仍可能漏检极小变化，不能把总体高分解释为每个样本都可靠。

## 7. 验证状态与边界

- 增量训练云端验收：9 passed。
- 最终本地 ONNX 交付环境：15 passed。
- 网站健康接口：`onnxruntime-siamese-resnet18`。
- ONNX 侧车元数据：输入尺寸 256，阈值 0.47，温度 1.730929，避免部署阈值与评估阈值不一致。
- 2026-07-23 最新大面积拆除 HTTP 回归：变化占比 25.2321%，6 个连续区域，引擎为 `onnxruntime-siamese-resnet18+structural-fusion`；标准示例为 5.4108%，5 个区域且不触发结构扩展。

以上指标只证明模型在 LEVIR-CD 建筑变化任务上的表现。没有新疆本地代表性测试前，不能宣称适用于新疆所有地貌、季节、传感器或灾害场景。
