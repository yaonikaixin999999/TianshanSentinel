# 软件需求规格说明书

## 1. 产品定义

系统面向课程实训中的遥感变化分析人员。用户上传同一区域的前后时相影像，系统返回变化区域叠加图、定量指标、斑块列表和风险提示，并保留审计历史。

## 2. 用户角色

- 分析员：创建分析任务、浏览结果、查看历史。
- 算法工程师：训练、评估、校准和导出模型。
- 运维人员：配置模型路径、运行服务和检查健康状态。

课程版不实现账号和权限；部署到公共网络前必须补充认证、限流和对象存储。

## 3. 功能需求

| 编号 | 需求 | 验收方法 |
|---|---|---|
| FR-01 | 上传前后时相 PNG/JPEG/TIFF | 两个合法文件返回 201 |
| FR-02 | 校验空文件、类型和大小 | 非法输入返回 4xx 及中文信息 |
| FR-03 | 自动统一尺寸并尝试配准 | 结果返回 `aligned` 字段 |
| FR-04 | 输出像素级变化概率 | 生成可访问叠加图 |
| FR-05 | 输出变化率、置信度、不确定性 | 数值均在 0 到 1 之间 |
| FR-06 | 提取变化斑块 | 返回位置、面积、置信度和风险 |
| FR-07 | 生成辅助研判结论 | 结论含斑块数、变化率和风险 |
| FR-08 | 保存分析历史 | 刷新页面后记录仍存在 |
| FR-09 | 提供统计看板 | 返回任务数、斑块数和风险分布 |
| FR-10 | 无模型演示 | 权重缺失时健康接口显示 heuristic |
| FR-11 | 模型热切换 | 重启后按 ONNX、PyTorch、启发式顺序加载 |

## 4. 非功能需求

### 性能

- 单图最大 20 MB，可通过环境变量调整。
- 推理服务同步处理单任务；课程演示期目标并发为 1-4。
- CPU 端必须记录实际平均时延，不在文档中预填数值。

### 可用性

- 桌面和手机宽度不发生控件重叠。
- 关键按钮有禁用和加载状态。
- 风险不能只靠颜色表达，同时显示中文标签。

### 可维护性

- 算法包与 Web 服务分离。
- 训练参数集中在 YAML。
- 数据库仅由仓储层访问。
- 公开 API 具有版本前缀 `/api/v1`。

### 安全和伦理

- 上传文件使用随机 ID，不使用原始文件名作为路径。
- 仅允许图像 MIME 类型，并通过 Pillow 再解码。
- 结果是辅助提示，不替代人工和现场核验。
- 涉及本地敏感遥感数据时，应部署在受控网络并设置保留周期。

## 5. 关键用例

### UC-01 创建变化分析

前置条件：后端在线；两期影像区域大致一致。

主流程：选择图像，点击“开始研判”，后端校验、配准、推理、后处理、保存，前端显示图像滑块和指标。

异常流程：格式不支持、文件过大、无法解码、推理异常；系统显示可操作错误，不产生半条历史记录。

### UC-02 查看审计历史

用户打开页面，系统读取最近 20 条记录。点击一行后恢复对应图像、指标和结论。

### UC-03 部署训练模型

算法工程师完成评估和校准，导出 `artifacts/model.onnx`，重启后端。健康接口的引擎从启发式切换为 ONNX。

## 6. 数据字典

| 字段 | 类型 | 含义 |
|---|---|---|
| `change_ratio` | float | 变化像素占整图像素比例 |
| `mean_confidence` | float | 变化区域平均概率；无斑块时表示稳定置信倾向 |
| `mean_uncertainty` | float | 两次翻转 TTA 预测的平均差异 |
| `region_count` | int | 面积超过阈值的连通域数量 |
| `overall_risk` | enum | low、medium、high |
| `aligned` | bool | ORB/RANSAC 配准是否通过内点检查 |
