# 选题定制说明

## 最终题目

**天山哨兵：基于多尺度注意力孪生网络的双时相遥感变化检测与可解释风险研判平台**

英文题目：**Tianshan Sentinel: An Explainable Bi-temporal Remote-Sensing Change Detection and Risk Assessment Platform Based on a Multi-scale Attention Siamese Network**

## 选题依据

参考实训方案的 20 个选题主要覆盖工业缺陷、目标检测、人脸、医学影像、风格迁移、文本分类、问答、推荐和结构化预测。班级已登记题目则集中于扩散模型、图像修复、时序预测、垃圾分类、RAG、医学影像、图像分类、垃圾短信和工业缺陷。两份清单中均无遥感双时相变化检测题目。

本项目并非把普通图像分类换一个应用名称，而是解决如下独立问题：输入不是单张图片，而是同一地理区域两个时间点的影像；输出不是类别，而是像素级变化图、变化斑块、变化面积、置信度、不确定性和审计记录。

## “高端”体现在哪里

1. 算法：共享权重孪生编码器、多尺度差异门控、U-Net 解码、边界约束损失。
2. 可信 AI：温度缩放校准、翻转 TTA 不确定性、低置信度提示，不把概率当作绝对真值。
3. 空间工程：ORB + RANSAC 自动配准，避免相机轻微偏移被误判为变化。
4. 部署：PyTorch 训练、ONNX Runtime CPU 推理、FastAPI 服务、Vue/ECharts 看板。
5. 审计：SQLite 保存输入、叠加图、引擎、风险等级、变化斑块和时间戳。

## 场景定位

- 城市建设变化审计：新建、拆除、扩建区域筛查。
- 工业园区巡查：场地、建筑和道路变化预警。
- 生态巡查辅助：水体、裸地、植被显著变化的候选区域发现。
- 灾后快速筛查：作为人工判读前的候选区域排序工具。

系统仅做辅助研判，不直接给出行政、执法或灾害处置结论。

## 可行性边界

- 训练阶段使用 LEVIR-CD 公开数据，任务与代码完全匹配。
- 新疆本地影像若无标注，可先做演示或域外测试；不能把公开数据集的指标表述为新疆实地精度。
- 轻薄本不承担训练，训练后的 ONNX 模型可在 CPU 上演示。
- 未训练时启发式模式仅用于验证软件链路，答辩时必须明确其性质。
